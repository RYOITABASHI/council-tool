# Council Tool 会議アプリ

複数の LLM が参加する会議を作成、閲覧する Expo アプリです。ホームの「セッション」から会議を選ぶと「会議」画面が開きます。「セッション」と「会議」の右上にある歯車から「設定」を開けます。

## 起動

```sh
npm install
npx expo start
```

Android 実機では、Expo SDK 58 に対応する Expo Go で起動時の QR コードを読み取ります。開発ビルドを使う場合は、Android 用の development ビルドを端末にインストールし、`npx expo start --dev-client` で接続します。ビルド方法は Expo の手順を参照してください。 [Android 環境のセットアップ](https://docs.expo.dev/get-started/set-up-your-environment/) · [開発ビルド](https://docs.expo.dev/develop/development-builds/introduction/)

## サンプル会議

ファサード URL を空にすると、ホームに同梱の実会議 2 件が表示されます。行をタップすると、その会議の状態とパケットを閲覧できます。サンプル会議は閲覧専用です。セッションの作成、＠メンション、承認・却下にはサーバー接続が必要です。接続を設定するには、サーバー未設定時に「＋」から「設定を開く」を選べます。

- `src/fixtures/meetings.json` に一覧用の会議概要を収録しています。
- `src/fixtures/live/` に会議 `97161c6b-8642-4a7e-bf78-4be1df5035bf` の状態とパケットを収録しています。
- `src/fixtures/proof/` に会議 `47445a40-d277-45c5-9349-eb7189de2ce3` の状態とパケットを収録しています。

## ファサード接続

「設定」の「接続」で、端末からアクセスできるファサードのベース URL と、サーバー側の `COUNCIL_HTTP_TOKEN` に対応するトークンを入力し、「保存」を押します。アプリ側の環境変数は不要です。接続設定は端末の AsyncStorage に保存されます。

ファサードへのリクエストには `Authorization: Bearer <token>` ヘッダーが付きます。

- `GET /meetings` でセッション一覧を取得します。
- `POST /meetings` で議題と席を指定してセッションを作成します。
- `GET /meetings/{meetingId}/state` で会議状態、ラウンド、受理状況を取得します。
- `GET /meetings/{meetingId}/packets` で oversight ビューのパケットを取得します。
- `POST /meetings/{meetingId}/start` で会議の実行を開始します。
- `GET /meetings/{meetingId}/runner` で実行状態を取得します。
- `POST /meetings/{meetingId}/mention` で指定した席にメンションを送信します。
- `POST /meetings/{meetingId}/approve` で会議を承認または却下します。

ファサード接続時は一覧を引っ張って更新できます。取得に失敗すると「再試行」と「サンプル会議一覧を見る」が表示されます。会議画面は「更新」または引っ張って再取得できます。

共有された会議 ID がある場合は、「設定」の「会議IDで開く」に入力して「開く」を押します。ファサード URL が空の場合は同梱データから会議を探します。

## セッションの作成

1. 「セッション」一覧の右上にある「＋」を押します。
2. 議題を入力し、エージェント席を 1 つ以上選びます。「設定」で保存したエージェント選択が初期値になり、作成画面でこのセッションの席を変更できます。初期設定の席は Codex (CLI) と Claude Code (CLI) です。API席・ローカル席は現在利用できません。
3. 「作成して開始」を押すと、会議が作成されて実行が始まり、会議画面が開きます。

作成後に開始でエラーが出た場合は、同じ会議の開始を再試行するか、「作成した会議を開く」を選べます。

## 会議の進行

- ファサード接続時は会議画面に戻ったときと、表示中は約 5 秒ごとに会議と実行状態を自動更新します。承認済みまたは却下になると自動更新は終了します。
- ヘッダーに実行状態の「実行中」「承認待ち」「エラー」「完了」が表示されます。エラーの詳細がある場合はチップの下に表示されます。
- ＠メンションは、会議がラウンド間または承認待ち（`AWAITING_APPROVAL`）で、進行中のラウンドがなく、実行状態が待機中、完了、エラー、承認待ちのいずれかの場合に送信でき、会議が承認待ちの間は「承認する」「却下する」ボタンと併せて利用できます。画面下の席から宛先を 1 つ選び、内容を入力して「送信」を押します。宛先を選ぶまでは入力欄と送信ボタンが無効です。
- 会議状態が承認待ち（`AWAITING_APPROVAL`）になると、「承認する」または「却下する」を選べます。確認ダイアログで確定すると会議状態が更新されます。

## 表示スタイル

- **ライン風**は、発言や照合結果をラウンド順に並べたタイムラインです。
- **スレッド風**は、発言をラウンドごとのセクションにまとめます。

「設定」または会議画面で選んだスタイルが保存され、次に会議を開くときに使われます。統合結果はどちらの表示でも末尾にあります。
